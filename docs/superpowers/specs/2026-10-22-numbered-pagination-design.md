# 数据列表服务端分页

用户要求：系统数据列表使用 Element Plus 分页交互，并补齐前后端分页；开发在本地，测试在云端。

主列表范围：主机、任务、制品集、hook、模板、审计/报表、账号管理及旧用户入口。统一默认每页 20 条，选项 10/20/50/100，显示真实总数、上一页/下一页、页码、跳页。切换筛选或每页条数回第一页；保存和刷新保持当前页，删除最后一条后回到有效末页。数据按页替换，不累积追加。公共分页状态拒绝过期请求覆盖当前查询，失败保留已显示数据并回退页码。

HTTP：七个主列表接受 `page`、`page_size`。传入任一参数即为页码模式，默认 page=1、page_size=20；page >= 1，page_size 1..500，拒绝非法字符串、负数、零、溢出及和 cursor/limit 混用。页码模式返回 `{items,next,total}`，total 为所有匹配过滤条件的真实记录数（包括 total=0）；next 保持既有游标语义兼容字段。没有页码参数的旧 cursor/limit 调用继续按旧约定工作，total 可省略。仓储查询新增 Page int，Limit 为实际页大小，Page=0 表示原游标模式；Page[T] 新增可选 Total *int64，避免给旧模式提供伪总数。不改变仓储接口方法签名。数据库执行筛选后的 COUNT 和有稳定排序的 LIMIT/OFFSET，绝不在 HTTP 层取完整列表后切片。

次级选择列表（建任务主机/ISO/模板、hook 候选）同步消除追加式无限列表，按其候选过滤语义分页，不能先分页再在前端过滤。已作为一个对象完整载入的版本/诊断等有限详情集合使用本地分页或固定高度视图，事件增量流维持原协议并限制可见行数，不能把选择跨页的既有行为破坏。

Element Plus 官方参考：https://element-plus.org/zh-CN/component/table 、https://element-plus.org/zh-CN/component/pagination 。沿用现有 Vben 表格与权限/编辑功能，新增统一 ElPagination 控件。OpenAPI 类型重新生成，旧 cursor 用户及 CSV 全量导出兼容。

验证：真实 PostgreSQL 各列表的分页与过滤总数、稳定次序、空页、非法参数、游标兼容；公共前端分页状态的过期响应/失败/页大小/末页回退；真实浏览器验证页码、总数、每页条数、筛选和账号弹窗保存。代码不在云端编辑，云端仅接收同步归档和执行检查。
