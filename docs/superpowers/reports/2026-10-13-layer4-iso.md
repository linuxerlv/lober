## 执行裁定与代价

以下是执行中对计划冲突和环境差异所作的全部实质裁定；没有借此扩大到后续阶段。

1. 按项目已确认的每层一个分支约定使用主检出 `feat/iso`，不建立 worktree。中文计划标题不适配技能的英文任务提取器，逐段读取原计划并维护执行记录；代价是必须手动核对任务边界。
2. PostgreSQL 18 的 RESTRICT 删除错误实测为 `23001`，增加仅针对已知外键删除约束的翻译，保留旧 `23503`；代价是未知约束仍返回原错误。已有测试与新增回归均通过。
3. catalog 返回导出的、深复制的 Media 视图和 ProbeKind，供 ISO 包跨包读取；代价是消费者依赖这组公开视图，而不是计划中的私有表类型。
4. SUSE 原标志无法区分格式和系，加入 Absent 标志及产品文本、移除固定 x86 路径；代价是实际介质布局还须逐系验证。
5. 第 3 层尚未合入，扩展现有守卫入口，并加入 ISO 包和未知内部模块检查；代价是合入第 3 层时需协调守卫结构。
6. 对独立的解析器、识别/WIM、来源获取划定互不重叠的文件所有权并行实现，主任务负责存储与导入集成；代价是集成期间包编译可能暂时依赖其他工作者尚未完成的文件。最终由独立新上下文审查整棵分支。
7. 未完成来源仅指 pending/fetching；角色使用可作文件名的 ValidIdent；相同起点区间保留较大长度，SaveRange 原子重算区间并增加 Rev；代价是调用者保存区间后须重新读取修订号。
8. 本地介质遵循总规格原地读取、不复制、不删除，使用允许根目录内的安全打开并在导入前后核对摘要；代价是操作者必须保持原文件稳定。
9. Register 只登记 pending，由装配点调用阻塞的 FetchOne 或等待 Upload，不在本包启动协程；代价是第 5 层需要显式调度。
10. 崩溃中的 fetching 恢复从实际持久化文件长度续传，显式 Retry 重置终止来源的字节和区间。Retry 在审计事务成功前暂存旧文件，回滚时恢复；代价是进程在此期间崩溃可能留下 `.retry-*`，上传暂存同理可能留下 `.chunk-*`，Recover 不做垃圾清理。
11. 用完成文件的摘要验证续传和乱序上传，Import 再独立验证一次；代价是大型介质增加顺序读盘。
12. 每个 staging 目录由一个 Sources 实例协调文件操作，数据库修订号协调状态；代价是不能让多个服务进程同时共用该 staging 目录。上传的 ResumeFetch 表示等待客户端继续上传。
13. 内网 IP 按已确认的气隙镜像需求放行；每个请求和重定向重新校验全部地址并固定拨号，保留原 Host、TLS SNI 和证书验证；代价是使用者仍需按部署需求控制允许的内网镜像来源。
14. Cancel 不等待下载锁，先持久化取消再取消 HTTP，后续旧修订号不能恢复 fetching/fetched；代价是文件写入和状态变更须独立处理竞争与回退。
15. 固定 series/version/arch 发布目录禁止覆盖其他 ISO；所有权标记及内容比较用于自身崩溃后的复用。代价是同一平台目录不能并存内容不同的镜像，Windows 同 major.minor 的不同 build 也受此限制。
16. 保留存储既有 DuplicateError 及 Existing ID，不新增计划之外的重复原因代码；导入错误保存在主来源 Error，成功状态仍以 ISO 为准。
17. WIM ARCH=0 根据 Microsoft 的定义是 32 位，不能按计划误标为 x86_64；仅支持 catalog 中的 9/x86_64 与 12/aarch64。代价是 32 位安装介质明确不受支持。
18. Debian 官方 netboot mini.iso 不要求 dists，使用专门的 disk-info 探测，必须有 netboot 标志且版本、架构匹配主盘；代价是无法验证版本的 tar.gz 形式暂不支持。
19. 无第 3 层代码时不伪造 render 或 golden；Task 9 只完成文档与测试开关，render 角色表与地址/golden 联调等待合入，控制台类型断言等待第 5 层。
20. 无期望 SHA256 时重新下载完整远程实体，有摘要时才续传并在发布前验证；代价是没有摘要的断线下载不能复用旧字节，但不能静默拼接新旧资源。
21. 删除接缝使用带 ISO 与 Sources 的 DeletionSnapshot，保留本地原件身份，成功审计删除后才做幂等清理；代价是第 5 层须持久化完整快照与清理重试队列，Recover 不负责已删除记录。
22. 缺失辅助来源的 failed ISO 可补登记、获取、取消、重试并重导，主来源保持不变，ISO 粗状态保留 failed；代价是控制台须读取来源进度，不能只靠 ISO.State 表示补齐过程。
23. 最终数据库提交错误使用不继承取消、最长 5 秒的读取核实；只在确认尚未 ready 时回滚发布，未知结果保留。代价是失败可能留下自有目录，重启 Import 可比较复用，不能用删除文件猜事务结果。
24. 全部复制结束后复核主盘及辅助盘；发布符号链接按 OS 根约束验证完整链，解析器也按逐段展开语义处理父目录。代价是大型介质多一次读取，断链和循环链接明确拒绝。
25. Windows 对取消及输出 IO 故障的误分类虽在审查中标作 Minor，其效果会误导重换安装盘并改变取消语义，因此按必须修复处理；只把不存在或不合格的输入转换成缺制品错误。
26. HTTP、render 合入和主分支合并没有纳入此次开发授权；提交并保留现有 feat/iso 供后续集成，不推送或合并。执行证据在本报告留存后清理本计划的临时工作目录，其他任务文件保留。
27. 续传重启测试用已持久化的部分文件及新 Sources 实例模拟进程中断，不把它声称为实际 OS kill；代价是没有覆盖操作系统强制终止瞬间的完整外部系统行为，该部分留给装配点验收。
