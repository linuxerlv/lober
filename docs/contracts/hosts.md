# 主机登记与 CSV 契约

这份约定固定第三阶段迁移前的主机行为。六条真实路由仍以 `internal/interfaces/console/hosts.go` 为准。迁移不增加字段、分页方式或导入规则。

## 六条入口

| 入口 | 权限 | 成功结果 | 审计动作 |
| --- | --- | --- | --- |
| `GET /console/v1/hosts` | `host:read` | `HostPage` | 无 |
| `GET /console/v1/hosts/:sn` | `host:read` | `HostResponse` | 无 |
| `POST /console/v1/hosts` | `host:write` | 新主机，`rev=1` | `host.create` |
| `PUT /console/v1/hosts/:sn` | `host:write` | 整条替换，`rev+1` | `host.update` |
| `DELETE /console/v1/hosts/:sn?rev=...` | `host:write` | `null` | `host.delete` |
| `POST /console/v1/hosts/import?dryRun=...` | `host:write` | 预演为 `CsvPlan`，提交为 `HostPage` | 预演无；提交每台一条 `host.import` |

五角色都能读。只有管理员 `admin`、操作员 `operator` 能写，导入预演也要求写权限。查看者 `viewer`、编写者 `hook-author`、审批者 `hook-approver` 写入返回 403。未登录、会话失效、账号禁用或角色无效返回 401；强制改密码返回 403。网页继续读取当前账号检查权限。

成功均为 200，外层为 `{code:0,data:结果,message:""}`。失败保留 `code,data,message`，`code` 等于响应状态；没有错误明细时 `data:null`。

| 网页类型 | 字段 |
| --- | --- |
| `HostRequest`、`HostResponse` | `sn,arch,firmware,attrs,rev`；架构和固件可空，返回时空属性为 `{}` |
| `HostPage` | `items,next,total?`；空列表为 `[]`，没有下一页时 `next:""` |
| `HostQuery` | `prefix,attr_key,attr_value,cursor,limit,page,page_size` |
| `RevisionQuery` | `rev`，正整数 |
| `ImportQuery` | `dryRun` |
| `CsvRow` | `row,sn,action,problems`；无问题为 `[]` |
| `CsvPlan` | `rows,total`；保持文件记录顺序 |

以上公开名称、字段及接口说明中的可选架构、可选固件、`text/csv` 和两种导入结果保持。请求中没有可信审计字段。操作者来自当前账号，动作来自固定路由，时间来自注入时钟；审计详情为空。审计与写入共用事务。读取、预演及 CSV 拒绝不写审计，也不读取写入时钟；整批导入共用一个时间，不增加通知。

## 列表和分页

列表使用 `prefix`，按原文匹配，不先把小写转大写。例如 `prefix=sn-1` 不匹配 `SN-1`。它不采用向导 `q` 的规范化规则。

属性键和值必须成对提供，按原文精确过滤。`rack= A01 ` 与 `rack=A01` 不同。不增加属性键格式校验，不裁剪属性值。

主机按编号字节序排列，例如 `SN-1,SN-10,SN-2`。游标是不可解释的位置字符串，调用方原样传回。

| 模式 | 选择方式 | 默认和边界 | 返回 |
| --- | --- | --- | --- |
| 游标 | 没有 `page/page_size` | 默认 100，最多 500；`limit=0` 等同省略 | 无 `total`，有下一页时 `next` 非空 |
| 页码 | 出现 `page` 或 `page_size` | 默认第 1 页、每页 20；正整数，每页最多 500；拒绝偏移量溢出 | 含 `total`，仍保留 `next` 字段 |

页码模式不能同时出现 `cursor/limit`，即使它们为空。空页码、重复页码字段、非法数字及数字溢出返回 400。空列表仍输出 `items:[]`。

## 单条写入与错误先后

1. 读取单台和单条写入沿用 `model.NormalizeSN`：去首尾空白，先检查只能包含允许的 ASCII 字符，再转大写。非法编号为 `sn_invalid`，出厂占位编号为 `sn_placeholder`，保留问题定位。`ſn-1` 不能变成 `SN-1`。
2. 创建先解析正文，再规范化编号，再调用仓储。空编号返回 422。请求 `rev` 可为任意值，创建结果由仓储置为 1。架构、固件可空，属性整份保留，不额外解释属性值。
3. 更新先解析正文，再检查 `rev>=1`，再规范化路径编号；正文 `sn` 非空时再规范化并与路径比较，最后才访问记录。坏版本与编号同时出现时先返回 400；版本合法且编号非法时返回 422 及编号问题。正文与路径不同返回 400。正文可省略 `sn`，但不能更改主机身份。
4. 更新是整条替换。省略 `arch/firmware/attrs` 表示清空，不合并旧值。成功后版本加 1；旧版本返回 409。
5. 删除先解析正的 64 位整数 `rev`，再规范化路径编号，再检查存在性、版本和任务引用。版本溢出与编号非法同时出现时先返回 400。不存在为 404，旧版本或任何任务引用为 409；已结束任务的引用也阻止删除。删除后再次删除为 404。
6. 重复创建为 409。仓储问题清单为 422 及 `problems`；普通无明细非法输入为 400，不存在为 404，重复、版本及引用冲突为 409。未知错误为 500，提示不含内部错误。保持既有仓储检查与审计检查的先后。

## CSV 预演与提交

1. 正文原样读取。先检查 `dryRun`，再读正文和解析 CSV。省略为 false；仅精确的 `true/false` 有效，空值、`TRUE`、`1` 等返回 400。重复参数保留 Gin 1.12.0 的首值规则，例如 `true&dryRun=no` 仍预演，`false&dryRun=true` 仍提交。读取正文失败为 400。不新增媒体类型强制检查或正文大小限制。
2. 只去掉文件开头的字节顺序标记。表头去首尾空白后检查重复及合法性，必须有 `sn`。`sn/arch/firmware` 为内容字段，其余列作为属性；`rev` 不成为版本控制列。保留标准 CSV 引号、换行、空行、列数与回车换行处理。
3. 无数据、缺 `sn`、坏表头、列数或引号错误为 400、`data:null`，保留原 CSV 提示。文件后段格式错误也使整份失败，不返回前半份计划，不读写主机仓储。
4. 行问题先放编号问题，再放 `Host.Validate` 的平台和属性问题，保持原顺序。仅对能规范化的编号查批内重复。全部重复位置均标 `error`，各行问题首项是 `host_duplicate_in_batch`。编号能规范化就显示规范值，否则保留原文。
5. `row` 是 `encoding/csv.FieldPos(0)` 的物理行号。引号内换行不改变后续定位为真实文件行号。属性内容不裁剪，不增加行列定位。`total` 包含全部记录。
6. 完成文件解析后，先用有效且唯一的编号调用一次 `GetHosts`，即使集合为空。读取发生在判断预演或行拒绝之前。因此有效行与错误行混合、且读取失败时仍返回 500，不能先返回 422 或把记录标为新建。
7. 没有行问题的已有主机标 `update`，其他有效主机标 `create`。`dryRun=true` 总是返回 200 及完整计划，可以包含坏行；不写记录或审计。正式请求有坏行则整份返回 422，`data` 为同一计划，提示取文件顺序第一条错误行的第一问题。
8. 正式有效请求只调用一次 `ImportHosts`。已有编号整条覆盖且版本加 1，新编号版本为 1；不比较 CSV 中的版本。预演不占用编号，也不承诺之后仍是新建或更新。成功按输入顺序返回实际保存结果，`next:""`，无 `total`。
9. 一台主机、审计或事务取消失败，整批记录、版本和审计都回滚。仓储仍按 `hostLockOrder` 排序加锁，在同一事务分块写入，结果保持输入顺序。不逐条提交、自动重试或事后补审计。
10. 上下文原样传给仓储。纯解析和内存计算不额外增加立即取消检查；空集合读取或尚未访问数据库的旧边界不扩大成新的取消承诺。
